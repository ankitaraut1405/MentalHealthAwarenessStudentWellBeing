Mental Health Awareness & Student Well-Being Survey

# About the Project

This project is a BSc Data Science college project focused on understanding mental health awareness and student well-being.

The project combines a student survey, Python-based data analysis, a visual analysis dashboard, and an informational website with a rule-based chatbot.

# Project Objectives

- Understand students' awareness of mental health.
- Study students' views about mental health and physical health.
- Analyze academic pressure and emotional well-being.
- Explore factors such as sleep, screen time, physical activity, and social support.
- Present survey results using graphs and percentages.
- Provide mental health awareness information through a website.
- Provide a simple informational chatbot for students.

# Project Components

# 1. Survey

A Mental Health Awareness & Student Well-Being Survey was created to collect responses from students.

# 2. Python Data Analysis

Python was used to:

- Load the survey dataset
- Understand the data
- Check and clean the data
- Analyze individual questions
- Calculate percentages
- Create graphs
- Compare different survey factors
- Analyze open-ended responses
- Identify major patterns and findings

# 3. Website

The website contains:

- Home page
- Mental health awareness information
- Student support information
- Well-being information
- Survey section
- Analysis dashboard
- Informational chatbot

# 4. Analysis Dashboard

The dashboard presents survey results through visual charts and key findings.

# 5. Chatbot

The website includes a simple rule-based chatbot that provides general information about:

- Mental health awareness
- Student well-being
- Academic pressure
- Sleep
- Screen time
- Physical activity
- Social support
- Survey and project information

The chatbot is intended for general educational information and is not a replacement for professional mental-health care.

# Dataset

The project uses survey responses collected through the Mental Health Awareness & Student Well-Being Survey.

The dataset contains responses to questions covering:

- Demographic information
- Mental health awareness
- Help-seeking awareness
- Social support
- Academic pressure
- Emotional well-being
- Sleep
- Screen time
- Physical activity
- Open-ended student opinions
